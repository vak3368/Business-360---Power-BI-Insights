## 📖 Project Overview

Business Insights 360 is an end-to-end Business Intelligence dashboard developed using Microsoft Power BI for **AtliQ Hardware**.

The dashboard provides management with a centralized platform to monitor and analyze business performance across multiple departments, enabling faster and data-driven decision-making.

---

## 🎯 Business Problem

AtliQ Hardware needed a unified reporting solution to monitor key business metrics across Finance, Sales, Marketing, Supply Chain, and Executive functions.

This dashboard consolidates data into a single interactive platform, helping stakeholders identify trends, measure KPIs, and make informed strategic decisions.
